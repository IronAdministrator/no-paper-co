# NO_PAPER foundations

These tokens come from the Figma file and live in `src/design-system/tokens.ts` and are wired into UnoCSS in `uno.config.ts`. Every component uses them through UnoCSS
utilities (for example `bg-surface`, `text-primary`, `rounded-card`, `font-heading`), so changing a value there
updates the site and this documentation together.

## Styling rules

- Use UnoCSS utilities and the shortcuts in `uno.config.ts` first.
- Reach for plain CSS only when utilities can't express it (gradients, masks, keyframes), and put it in the
  component's `<style scoped>` block.
- Global CSS is limited to fonts and the page base in `src/style.css`.
